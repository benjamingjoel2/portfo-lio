# benjamin — portfolio

one-page portfolio website for benjamin, designer & developer at tourground.

built with vanilla html5, modern css, and lightweight vanilla javascript.

## features
- editorial minimal aesthetic inspired by [bleibtgleich.dev](https://bleibtgleich.dev/)
- strictly all-lowercase typography and styling
- responsive interactive custom cursor and cursor-following work previews
- slot-machine scramble count-up animation on statistics
- 185-country rollout progress meter
- live local time (wat) and geo-coordinates
- one-click email copy with instant toast confirmation
